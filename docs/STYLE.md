# 风格拆解：点之战

> 这是 dotkit 唯一的「知识」文档。AGENTS.md 和 SKILL.md 只负责指路，具体规则都在这里。

灵感来源：[@aicreataro《点之战》](https://x.com/aicreataro/status/2106236856979607569)（20 秒，24fps，约 129 BPM）。
原作的流程是 Seedance 2.0 生成打斗画面和声音 → Python + Blender 把画面变成点 → AE 剪辑。
dotkit 用纯 Python（numpy + OpenCV）重做了整条流程，不需要 Blender 和 AE。

---

## 1. 核心一句话

**同一段打斗素材，每半拍换一种「点」的画法；到了重拍就对点动手：压扁、炸开，或者定格后绕着转。**

原作者总结了四条，都在原片画面里验证过：

1. **点距决定能不能认出人。** 点太大看不出是什么，太小又不酷。点距在 7–60 像素（1920 宽）之间切，大部分时间 10–16。
2. **半拍切一次（约 0.23 秒 / 5–6 帧）。** 一拍一切太慢；加上重拍时把点打碎，画面才「凶」。
3. **中间一定要停一下。** 一直快切会腻，插一段定格 + 环绕，前后的快切才显得快。
4. **炸要小、要短。** 每下都炸，人就认不出来了。多数重拍只压扁 3 帧；真正炸开全片只有 2–3 次。

## 2. 段落模板（原片 20 秒，按秒）

`dotkit auto` 就是按这个模板等比缩放、再把边界吸到拍点和重拍上。

| 原片时间 | 段落 | 画面 | 作用 |
|---|---|---|---|
| 0–1.25 | 原画 + 闪现 | 原画慢放，单帧闪出满屏点阵，间隔越来越短 | 先让观众认清「两个人在打」 |
| 1.25–1.35 | 色散 | 原画 + 强 RGB 色散 2 帧 | 过门 |
| 1.35–2.0 | **第一次炸** | 整个画面（连背景）碎成点扑向镜头，近的点变成焦外大圆盘 | 第一个重拍 |
| 2.0–3.25 | 拉出 | 从几个巨大的圆点开始拉远，点越来越细，人物显形 | 喘口气 |
| 3.25–9.7 | **节拍轮换** | 每半拍一个 look，镜头缓推；重拍压扁 + 色散 | 主体 |
| 9.7–12.0 | **定格 + 环绕** | 时间停住，点云有厚度，镜头绕人转；每拍换 look | 节奏变化 |
| 12.0–13.8 | 扯散 | 发光点流走、拉丝 | 过渡 |
| 13.8–16.3 | **彩色残影** | 亮色纯底，人身后拖一串彩色残影，重拍炸白光 | 第二个高点 |
| 16.3–18.0 | **终炸** | 黑底，点放射状冲向镜头，运动模糊拉出放射线 | 高潮 |
| 18.0–20.0 | 消散 | 白闪 → 细点 → 白点变稀 → 只剩几个大白点 | 结束 |

## 3. look 词典（`dotkit/looks.py`）

颜色都是从原片吸的。`dotkit looks <src目录>` 会把全部 look 画在同一帧上拼成一张对照图。

| 类 | look | 画法 |
|---|---|---|
| 纯色底 + 单色半调 | `cream_navy` `blue_white` `yellow_black` `cyan_black` `orange_black` `magenta_white` `white_navy` | 暗处点大、亮处点消失 |
| 黑底剪影 | `black_pink` `black_salmon` | 整块一种颜色，点一样大 |
| 原色点 | `orig_dense` `orig_mid`（只画人）、`orig_field` `orig_coarse`（背景是小红点）、`red_full`（满屏）、`square_full`（方块） | 点的颜色取自原画 |
| 发光散点 | `gold_glow` `purple_glow` `white_sparse` `white_bokeh` | 深色底 + 一个亮色 + 辉光，点随机大小 |
| 墨团 | `orange_blob` | 橙底上黑色大圆点粘连（配色散） |
| 闪现 | `glimpse` | 满屏原色大点阵，只用于开头的单帧闪现 |

**排列规律：亮底和暗底交替；发光散点隔几拍出现一次；不要连续两个同类。**

## 4. 打击事件（`E.hit(t, kind)`）

| kind | 效果 | 用在 |
|---|---|---|
| `squash` | 点被压扁 3 帧 | 大多数重拍 |
| `ca` | RGB 色散，4 帧衰减 | 和 squash 一起 |
| `flash` | 白闪 1 帧 | 段落切换、定格开始、镜头切点 |
| `burst` | 人物炸成发白光的大点 3 帧 | 最重的一两下、残影段的重拍 |
| `pop` | 点放大 3 帧 | 轻的强调 |

## 5. 关键技术点（为什么这样实现）

1. **人物遮罩 + 深度是一切的基础。** 遮罩决定哪些格子有点；深度把点反投影成三维点云。默认机位下点正好落回原位置，所以平时是平面点阵，一转机位就露出厚度。
2. **点阵布在源画面上，不是屏幕上。** 所以推镜头时点会变大（「拉出」段的巨大圆点就是推近了的点阵）。
3. **转机位时点要有厚度。** 每个点往后挤出几层（`Cam(extrude=…)`），否则人物是一张纸片。
4. **焦外是圆盘，不是高斯模糊。** 离焦越远，圆盘越大、越透明，边缘只给一点柔。
5. **放射状拉丝 = 运动模糊。** 一帧里采 4–6 个子帧取平均（`shutter=6`），炸开的速度要匀（`'lin'`），不能一下就停。
6. **残影** = 过去几帧的人画成单色，垫在后面。

## 6. 素材相关的规则（做原创片时学到的）

- **素材的选择：** 纯色或简单背景、1–2 个人、动作幅度大、5–20 秒。AI 生成（Seedance / 即梦 / Kling）的打斗片段最合适。
- **素材又暗又灰（黑衣服 + 灰背景）：** 所有 look 开 `levels=1`（人物内自动拉色阶），原色点换成双色（钢蓝 → 暖白）。`dotkit auto` 会自动判断，也可以用 `--style dark` 强制。
- **素材自带的声音和画面同步时：** 除了定格，源画面跟着时间走（`src = 镜头起点 × 24`），刀碰刀的声音才对得上。`dotkit auto` 不给 `--audio` 时就是这个模式。
- **音乐快（160 BPM 以上）时按拍换，不按半拍：** 一拍约 0.36 秒，正好接近原片半拍的速度。只在终炸前 1 秒左右改成半拍加速。
- **定格环绕只配密的 look：** 散点 / 发光点挤出厚度后会变成横向短线，人认不出来。
- **残影 4 层、隔 1 帧就够：** 素材本来就在动，6 层 × 隔 2 帧会糊满整个画面。
- **镜头切换处：** 残影要设 `floor`（不然把上一个镜头的人拖进来）；切点本身用「原画 + 色散 + 白闪」当转场。

## 7. 已知局限

- 深度是单张图估计的，人物内部起伏偏平；转机位超过 ±40° 会露馅。
- 刀、棍这类细东西只有 1–2 像素宽，大多变不成点（原画段和最密的 look 里能看到）。
- 景深和辉光是近似算法，不如 Blender 物理渲染真实。
